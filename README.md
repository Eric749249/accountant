# 首相感情分析ダッシュボード (PM Sentiment Dashboard)

YouTubeのコメントデータに基づき、特定の政治家に対するネット上の感情（特に「応援」や「個人的な好き嫌い」）を分析・可視化するWebアプリケーションです。

## 背景・課題

政治家の評価は「支持・不支持」で語られがちですが、実際のネット上の声は、より感情的な「応援したい」「個人的に好き」といった気持ちに大きく左右されているのではないか、という仮説がありました。

特に、高市早苗氏に向けられるコメントには、他の政治家（例：石破茂氏、岸田文雄氏）と比較して、政策論争よりも個人的なキャラクターや期待感に基づく熱烈な応援や批判が目立つと感じていました。この直感をデータで検証し、ネット世論の新しい側面を可視化したいと考えたのが、このプロジェクトの出発点です。

## 機能

- **データ収集:** Google (YouTube) APIを利用し、特定のキーワードに関連するYouTubeショート動画のコメントを自動で収集します。
- **感情分析:** 収集したコメントをOpenAIのGPT-4 APIに送信し、「応援」「批判」「中立」「不明」の4つに分類します。
- **可視化:** Streamlitを使用し、分析結果をインタラクティブなダッシュボードに表示します。

## 技術スタック

- **言語:** Python
- **API:** Google API (YouTube Data API v3), OpenAI API (GPT-4)
- **フレームワーク/ライブラリ:** Streamlit, Pandas
- **実行環境:** ローカル環境

## こだわった点・工夫

このプロジェクトは、私自身の「バイブス・コーディング（AIとの対話による高速開発）」スタイルを確立したものです。具体的なコーディング技術の苦労よりも、**「何を明らかにしたいのか」という要件定義**と、**「どういう切り口で分析すれば面白くなるか」という発想**に最も時間をかけました。

- **独自の分析軸:** 単純なネガポジ判定ではなく、「応援」という新しい軸を立てて分析した点。
- **プロトタイピング:** Streamlitを採用することで、データ分析からWebアプリとしての可視化までを迅速に実現しました。
